# หน้าแรก: ไฟล์ของคุณอยู่ที่ไหน

หน้าแรกคือหน้าเริ่มต้นของ GenOffice: แถบนำทางอยู่ทางซ้าย ส่วนรายการไฟล์และการ์ดสร้างด่วนอยู่ทางขวา

![หน้าแรก](img/home-screen.png)

## การนำทางในแถบด้านข้าง

- **ล่าสุด**: ไฟล์ที่คุณเปิดล่าสุด แต่ละแถวจะมีเวลากำกับ — วันนี้ เมื่อวาน หรือวันที่
- **รายการโปรด**: ไฟล์ที่คุณทำเครื่องหมายดาวไว้ วางเลื่อนเมาส์เหนือแถวไฟล์แล้วคลิกดาวเพื่อเพิ่มหรือนำออก **ย้ายไปกลุ่ม** ในเมนู ⋯ จัดไฟล์ที่ติดดาวเข้ากลุ่มที่มีชื่อ มุมมองติดดาวกรองตามกลุ่มเหล่านั้น
- **โฟลเดอร์**: ไดเรกทอรีที่คุณเพิ่มเข้าแถบด้านข้างด้วย **เพิ่มโฟลเดอร์…** หรือลากเข้ามาจากโปรแกรมจัดการไฟล์ แต่ละรายการจะกลายเป็นรากที่คุณเปิด สร้างโฟลเดอร์ย่อยข้างใน เปลี่ยนชื่อ และนำออกได้ รายการที่ออฟไลน์จะแสดงว่าไม่พร้อมใช้งานและนำออกจากรายการได้ **โฟลเดอร์ใหม่** สร้างอีกรายการหนึ่ง

ที่นี่ไม่มีรายการถังขยะ ไฟล์ที่ลบจะไปอยู่ในถังขยะของระบบ การกู้คืนเป็นหน้าที่ของระบบปฏิบัติการ

## รายการไฟล์

แต่ละแถวจะแสดงไอคอน ชื่อไฟล์ เวลาที่แก้ไข และข้อมูลอื่น **⋯ เมนู** ของแถวมีตัวเลือก:

- **เปิด** และ **แสดงในโฟลเดอร์** เพื่อค้นหาตำแหน่งไฟล์ในโปรแกรมจัดการไฟล์ของคุณ
- **คัดลอกเส้นทาง**
- **ย้ายไปยังโฟลเดอร์…**: เปิดตัวเลือกโฟลเดอร์และย้ายไฟล์จริง หากปลายทางมีไฟล์ชื่อเดียวกันอยู่แล้ว คุณจะข้าม เขียนทับ หรือเปลี่ยนชื่อได้
- **เปลี่ยนชื่อ**: เปลี่ยนชื่อแบบอินไลน์ โดยคงนามสกุลไฟล์ไว้ให้อัตโนมัติ
- **เพิ่มในรายการโปรด / นำออกจากรายการโปรด** — ดาวจะคงอยู่หลังปิดแล้วเปิดใหม่ และติดตามไปกับไฟล์เมื่อคุณเปลี่ยนชื่อ
- **สร้างสำเนา**: สร้างสำเนาไว้ในโฟลเดอร์เดียวกัน
- **ลบ**: ย้ายไฟล์ไปยังถังขยะของระบบ ไม่ใช่การลบถาวร
- **นำออกจากรายการ** ในมุมมอง **ล่าสุด** ระดับบนสุด เพื่อเอารายการออกโดยไม่แตะไฟล์

### หลายไฟล์พร้อมกัน

ติ๊กช่องของแถว หรือ ⌘/ctrl-click เพื่อเลือกหลายรายการ ช่องของส่วนหัวจะเลือกทั้งหมดที่แสดงอยู่ตอนนี้ และแถบเหนือรายการจะบอกว่าเลือกไว้กี่รายการ (**เลือกแล้ว {n} รายการ**) พร้อม **ย้ายไปยังโฟลเดอร์…** และ **ลบไฟล์** สำหรับทั้งชุด คุณยังสามารถลากรายการที่เลือกหลายรายการไปวางบนโฟลเดอร์ในแถบด้านข้างได้

## การค้นหา

ช่องค้นหาด้านบนค้นหาสองอย่างพร้อมกัน:

- **ชื่อไฟล์**: กรองตามชื่อได้อย่างรวดเร็ว
- **เนื้อหาไฟล์**: GenOffice จัดทำดัชนีไฟล์ของคุณอยู่เบื้องหลัง (ข้อความในไฟล์ docx/xlsx/pptx/pdf/md/html) การค้นหาจากข้อความในเนื้อหาจึงหาไฟล์เจอด้วย

## การ์ดเริ่มต้นอย่างรวดเร็ว

การ์ดเหนือรายการไฟล์สร้างเอกสารใหม่ได้ในขั้นตอนเดียว การคลิกการ์ดจะสร้างไฟล์ประเภทนั้นและเปิดตัวแก้ไขของมันขึ้นมา คุณเริ่มพิมพ์ได้ทันที

ไฟล์ใหม่จะไปอยู่ในโฟลเดอร์ที่เลือกอยู่ในแถบด้านข้าง หากไม่ได้เลือกไว้ก็จะไปยังโฟลเดอร์เริ่มต้น

แต่ละการ์ดทำอะไร:

- **Docs** (.docx): เอกสารข้อความว่างในตัวแก้ไข Docs ไฟล์จะถูกเขียนลงดิสก์เมื่อ **บันทึกครั้งแรก** เท่านั้น
- **Sheets** (.xlsx): สเปรดชีตว่างในตัวแก้ไข Sheets ก่อนที่คุณจะบันทึก ยังไม่มีไฟล์อยู่บนดิสก์ เพราะชื่อถูกกันไว้ให้การบันทึกครั้งแรก
- **Slides** (.pptx): งานนำเสนอว่างในตัวแก้ไข Slides
- **Markdown** (.md): เอกสาร Markdown ว่างในตัวแก้ไข Markdown
- **HTML** (.html): เว็บเพจว่างในตัวแก้ไข HTML
- **PDF** (.pdf): ต่างจากอีกการ์ด เพราะมัน **สร้างทันที** เป็น PDF ว่างหน้าเดียวของจริงในโฟลเดอร์เป้าหมาย แล้วเปิดเป็นไฟล์ปกติ (ตัวแก้ไข PDF ทำงานกับไฟล์จริง) เหมาะกับการใส่คำอธิบาย ปิดบังข้อมูล หรือเพิ่มข้อความ และไฟล์จะถูกตั้งชื่ออัตโนมัติตามเนื้อหาได้ตอนบันทึกครั้งแรก
- **เปิดไฟล์ในเครื่อง**: กล่องเลือกไฟล์ของระบบสำหรับ Word (.docx/.doc), Excel (.xlsx/.xlsm/.xls/.csv/.tsv), PowerPoint (.pptx/.ppt), PDF, Markdown (.md/.markdown) และเว็บเพจ (.html/.htm) เลือกได้หลายไฟล์ และแต่ละไฟล์จะได้แท็บของตัวเอง ไฟล์ข้อความ (.txt, .json) เปิดที่นี่ได้เช่นกัน — จะเข้าสู่มุมมองซอร์สของตัวแก้ไข Markdown

> เคล็ดลับ: เมนู ไฟล์ ▸ สร้างใหม่ ในแถบเมนูสร้างเอกสารชนิดเดียวกันได้ (⌘N/Ctrl+N เริ่มต้นเป็นเอกสารข้อความ) และการลากไฟล์เข้ามาในหน้าต่างจะเปิดไฟล์นั้น
