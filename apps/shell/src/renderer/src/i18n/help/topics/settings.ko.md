# 설정, 언어와 테마

## 설정 열기

홈 화면 사이드바 아래쪽의 **설정** 버튼을 누르면 설정 패널이 열립니다. 패널은 일반과 정보 두 섹션으로 구성됩니다.

![설정 ▸ 일반 — 언어, 테마, 자동 저장, 사용량 통계 스위치가 있는 곳](img/settings-general.png)

## 언어

- 설정에서는 **21개의 UI 언어**를 제공합니다: 영어, 중국어 간체, 일본어, 한국어, 프랑스어, 독일어, 스페인어, 태국어, 인도네시아어, 러시아어, 아랍어, 포르투갈어, 이탈리아어, 폴란드어, 체코어, 네덜란드어, 말레이어, 히브리어, 힌디어, 중국어 번체, 베트남어.
- 전환은 즉시 적용되어 유지되며, 네이티브 메뉴 바도 그 언어로 다시 만들어집니다.

## 테마

라이트/다크/시스템 따르기 세 가지입니다. 시스템 따르기를 고르면 OS 화면 설정에 따라 바뀌고, 편집기 영역도 함께 바뀝니다(깜빡임 없음).

## 일반

- **익명 사용 통계 보내기** — 기본적으로 켜져 있습니다. Google Analytics 4를 사용해 공개 IP 주소와 전송 메타데이터를 보내며, 문서 내용이나 파일 이름은 수집하지 않고, 각 이벤트는 ".docx 열음" 같은 유형만 담습니다. 여기서 언제든지 끌 수 있습니다.
- **모든 문서 자동 저장** 는 모든 편집기에서 자동 저장을 기본으로 켭니다. 특정 창에 대해서는 여전히 끌 수 있습니다.
- **저장 위치** 와 **변경** 버튼, 그리고 **Office 문서 기본 앱** 으로 .docx / .xlsx / .pptx 을 GenOffice 가 처리하도록 지정합니다.

## 정보

- **버전**, 프로젝트의 GitHub 링크, **GitHub에서 스타 누르기** 버튼.
- **업데이트 채널**: 안정 버전 또는 베타 버전. 바꾸면 즉시 반영되어 업데이트를 확인하며, 베타 설치를 안정 버전으로 되돌리지는 않습니다.

## 기본 앱 연결

설정에서 .docx / .xlsx / .pptx / .pdf 등의 파일을 GenOffice로 열도록 등록할 수 있습니다(플랫폼 수준의 기본 앱 등록. 물으면 확인합니다).
